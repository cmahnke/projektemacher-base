# Shortcodes

This theme ships a collection of shortcodes. This section documents each of them, one page per shortcode, and explains the [shortcode helper system](shortcode-helper/) that automatically loads the assets (JS/SCSS/CSS) a shortcode requires.

The table of contents lists all shortcode pages; pages can be organized in subdirectories (see the [`html/`](html/), [`iiif/`](iiif/), [`print/`](print/), [`dates/`](dates/) and [`maps/`](maps/) groups there). Shortcode pages that require JavaScript include a live, working demo inline; additional example pages live in the [demo section](demo/).
