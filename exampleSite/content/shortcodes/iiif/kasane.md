# iiif/kasane

Embeds the [Kasane](https://github.com/nakamura196/iiif-kasane) viewer (`iiif-kasane`, University of Tokyo, MIT) as the `<iiif-viewer>` web component: 3D models, images, audio and video from IIIF manifests, enhanced with annotations, comparison and map views.

IIIF [Collections](https://iiif.io/api/presentation/3.0/#collection) are supported as well — they open with Kasane's collection browser in the structure side panel (see [iiif/collection](/shortcodes/iiif/collection/), whose default browser is this viewer).

## Parameters

| Parameter | Type | Required | Default | Purpose |
| --- | --- | --- | --- | --- |
| `manifest` | string | yes | — | URL or path of the IIIF manifest or Collection. Relative paths are resolved against the page, paths starting with `/` against the site base URL (for translated pages the default language's permalink is used) |
| `locale` | string | no | `en` | Viewer locale, `ja` or `en` |
| `class` | string | no | — | Additional CSS classes for the wrapper |
| `options` | string | no | — | JSON string with viewer options, e.g. `{"panelOpen":false}` (see the [iiif-kasane README](https://github.com/nakamura196/iiif-kasane)) |

## Example

```text
{{</* iiif/kasane manifest="/post/3d-models/manifest.json" */>}}
```

## Live demo

The Presentation 3 manifest [generated by this example site](/iiif/presentation-3/manifest.json), loaded via a site-absolute path:

{{< iiif/kasane manifest="/iiif/presentation-3/manifest.json" >}}

## Assets

The JS entry `ts/iiif/kasane.ts` (which just imports the `iiif-kasane/element` package) is bundled by the shortcode itself as an ES module — the element loads its stylesheet at runtime relative to the bundle URL, so the package stylesheet is published alongside it as `ts/iiif/style.css`. The wrapper SCSS `scss/iiif/kasane.scss` comes via the shortcode helper.
