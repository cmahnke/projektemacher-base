# dates/build-date

Renders the build/render time (`now`) as `<date class="build-date">` using the `:date_short` / `:time_medium` layouts.

Build time: {{< dates/build-date >}}

## Parameters

None.

## Example

```text
Built on {{</* dates/build-date */>}}
```
