# related

Renders a `div.related-post` box with an i18n heading (`relatedPosts`) around the inner content (markdownified) — a visual wrapper for "related posts" notes.

{{< related >}}See the [shortcodes overview](../) for other shortcodes.{{< /related >}}

## Parameters

None (inner content only).

## Example

```text
{{</* related */>}}
More about this in [another post](/post/other/).
{{</* /related */>}}
```
