Partials

The theme ships around 90 partials in layouts/partials/. They fall into three categories:

  1. Extension points — partials the site is expected to provide, the theme only calls them (with a warning fallback), see extension points
  2. Reusable building blocks — complete blocks (header, footer, viewers, …) that can be called from site layouts, several of them are already in use by sites built on this theme, see the categorized pages below
  3. Internal helpers — small utilities used by the templates of this theme; they are listed below for completeness, but are not considered a public API

Calling convention

Partials are referenced by their path below partials/, e.g. {{ partial "header.html" . }}. Some partials are dispatched dynamically by name — those double as a plug-in mechanism, see plug-in dispatch.

Pages in this section

  • Extension points — partials a site provides itself
  • Structural partials — head, header, footer, menu, pagination, list and page rendering
  • IIIF partials — image and presentation viewers, manifest building blocks
  • Print partials — building blocks for print editions
  • Media type partials — description blocks for books, postcards and works
  • Metadata partials — schema.org, CodeMeta and Linked Art
  • Plug-in dispatch — name based variants (tag cloud, GeoJSON popups)
  • Helper partials — functions, data lookups and services

Internal helpers (reference only)

These are used internally and not documented in detail: functions/arrays/*, functions/debug/*, functions/files/*, functions/i18n/*, functions/tags/tag2str, functions/iiif/presentation-version.html, hugo/site/AllPages, metadata/linked-art/getty-label.json, metadata/linked-art/wikidata-label.json, geojson/feature*.geojson, iiif/3/*.json, iiif/4/manifest.json, html/head/*, js/type.html, macros/remove-shortcodes.txt. Several of them are still usable from site layouts, see helper partials.
