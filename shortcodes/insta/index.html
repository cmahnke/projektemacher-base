insta

insta

Embeds an Instagram post via Instagram’s official embed markup. The result is rendered through the html/iframe-consent wrapper, so the post and its embed.js script are inserted only after the visitor accepts the external content notice.

Parameters

Parameter Type Required Purpose
0 (positional) string yes Instagram post ID or a full URL starting with http
caption named string no Replaces the caption Instagram extracts from the post; rendered with class="instagram-caption"

An argument starting with http is used as-is; any other value is turned into https://www.instagram.com/p/<id>/. The resulting permalink gets the utm_source=ig_embed&utm_campaign=loading query parameters and is used both for data-instgrm-permalink and the fallback link.

Pass caption to replace the post’s own caption with your own text. In that case Instagram’s data-instgrm-captioned embedding is suppressed and the HTML-escaped text is rendered next to the embed with class="instagram-caption". Without a caption, the fallback link text is the hardcoded English A post shared on Instagram. Unlike the mastodon shortcode, a missing positional argument does not abort the build — it produces a broken https://www.instagram.com/p// permalink instead.

Examples

By post ID:

{{< insta "BsOGulcndj-" >}}

By full URL, with a custom caption:

{{< insta "https://www.instagram.com/p/BsOGulcndj-/" caption="A post on Instagram" >}}

Notes

The consent overlay and toggle come from html/iframe-consent. The required ts/iframe-consent.ts and scss/iframe-consent.scss assets are loaded automatically through the shortcode helper system. After consent, the consent script re-inserts the embed’s <script> element so Instagram’s embed.js runs and calls window.instgrm.Embeds.process(); the consent styles center the resulting .instagram-media block.

The post is not fetched at build time — the embed (and the post’s own caption) are rendered by Instagram’s script in the browser. A caption attribute is the only text available to a static print/PDF rendering.
