Shortcodes

Shortcodes

This theme ships a collection of shortcodes. This section documents each of them, one page per shortcode, and explains the shortcode helper system that automatically loads the assets (JS/SCSS/CSS) a shortcode requires.

The table of contents lists all shortcode pages; pages can be organized in subdirectories (see the html/, iiif/, print/, dates/ and maps/ groups there). Shortcode pages that require JavaScript include a live, working demo inline; additional example pages live in the demo section.
