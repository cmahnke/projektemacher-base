iiif/presentation

iiif/presentation

Embeds a Presentation API manifest using the configured viewer (TIFY by default, see IIIF configuration): a div.iiif > div.viewer.presentation-api initialized by iiifPresentationViewer() with the manifest URL.

The manifest URL is resolved relative to the page permalink (translation-aware, .html stripped).

Parameters

Parameter Type Required Purpose
manifestUrl string yes Manifest path, relative to the page URL

Example

{{< iiif/presentation manifestUrl="subdir/manifest.json" >}}

Assets

Via the shortcode helper: JS ts/iiif/tify.ts, SCSS scss/iiif/presentation-tify.scss. For the Mirador variant and its build requirements see Mirador.
