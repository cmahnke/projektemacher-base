iiif/collection

iiif/collection

Browses a IIIF Collection. The browser is selected with the browser parameter — Kasane (default) or Mango:

  • kasane (default): the <iiif-viewer> web component opens the collection with its collection browser in the structure side panel: items open directly, nested collections are navigated (with a back button), and ordering can be switched between ‘as listed’ and ‘by date’ (with a timeline view). Presentation 2 collections are upgraded on load.
  • mango: the framework-free tree navigator @mango-iiif/collection-navigator and the @mango-iiif/iiif-viewer viewer, connected through Mango’s own adapter: a div.iiif > div.collection-browser containing a mango-collection-tree and a viewer pane. Selecting a manifest in the tree loads it in the viewer pane without reloading the page. Nested collections are expanded lazily, only expanded branches are loaded. The first manifest of the collection is displayed initially, provided the collection contains manifests on the first level (optionally within loaded child collections).

The default browser can also be set site-wide via [params.iiif] collectionBrowser = "mango"; the shortcode parameter wins.

Parameters

Parameter Type Required Default Purpose
collectionUrl string no — Collection URL, resolved relative to the page URL. Defaults to the collection generated for the site’s home page (iiif-collection output)
browser string no kasane Browser: kasane or mango
height string no 80vh (mango) / A4 aspect ratio on desktop, 24rem on mobile (kasane) CSS height of the browser area
locale string no en Viewer locale, ja or en (kasane only)
class string no — Additional CSS classes for the wrapper (kasane only)
options string no — JSON string with viewer options (kasane only, see the iiif-kasane README)

The former sortMode and dateDiscovery parameters were removed: the Mango tree runs with its upstream defaults, while the kasane browser provides its own ordering UI.

Examples

Using the collection generated by this example site itself with the default (kasane) browser:

{{< iiif/collection >}}

The same collection with the Mango tree browser:

{{< iiif/collection browser="mango" >}}

An external collection at a custom height:

{{< iiif/collection collectionUrl="https://wellcomelibrary.org/iiif/collection/b19974760" height="60vh" >}}

Localization

The Mango tree strings are translated automatically for German pages; other languages fall back to the upstream English defaults. The kasane browser supports English and Japanese, selected with the locale parameter.

Assets

The Mango mode’s JS ts/iiif/collection.ts is bundled by the shortcode itself with esbuild code splitting (ESM, lazy renderer chunks); the kasane mode bundles ts/iiif/kasane.ts the same way (see iiif/kasane). Both wrappers’ SCSS (scss/iiif/collection-mango.scss and scss/iiif/kasane.scss) comes via the shortcode helper.
