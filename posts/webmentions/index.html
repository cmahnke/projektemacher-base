Webmentions

The theme advertises a webmention endpoint in the document head when params.webmentions.endpoint is configured:

[params.webmentions]
  endpoint = 'https://webmentions.example.org/endpoint.php'
  advertisePingback = true

Received mentions are collected by the theme’s PHP collector, synced to the repository’s webmentions data branch and fetched into data/webmentions/mentions.json at build time. The list below renders the entries for this page (sample data for this demo):
